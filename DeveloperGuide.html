3. Konfigürasyon Rehberi

3.1 appsettings.json - Ana Konfigürasyon

AdminUI - Admin Panel URL Ayarları

{
  "AdminUI": {
    "DevServerUrls": ["http://localhost:3000", "http://127.0.0.1:3000"],
    "ProductionUrl": "https://admin.yourdomain.com",
    "RedirectUrl": "http://localhost:3000/admin"
  }
}
AlanAçıklama
DevServerUrlsGeliştirme ortamında CORS izinli URL'ler
ProductionUrlÜretim ortamı URL'i (CORS için)
RedirectUrl/admin isteğinde yönlendirilecek adres

ModuleParsing - Modül Belirleme Kuralları

{
  "ModuleParsing": {
    "PathPatterns": [
      { "Prefix": "moim/api/v1/internet", "ModuleSegmentIndex": 4 },
      { "Prefix": "api", "ModuleSegmentIndex": 1 }
    ],
    "ModuleAliases": {
      "billlimit": "Bill",
      "genericmessages": "GenericMessages"
    }
  }
}
✅ Örnek:
URL: /moim/api/v1/internet/auth/login
Segments: [moim, api, v1, internet, auth, login]
Index 4 = auth → Modül: Auth

GatewayAdmin - Admin API Güvenlik

{
  "GatewayAdmin": {
    "Enabled": true,
    "IpWhitelist": ["127.0.0.1", "::1", "10.0.0.0/8"],
    "ApiKeys": [
      {
        "Name": "DevOps-Team",
        "KeyHash": "sha256:3b612c75...",
        "Permissions": ["read", "write", "emergency"],
        "IsActive": true
      }
    ]
  }
}
AlanAçıklama
IpWhitelistİzin verilen IP adresleri/CIDR blokları
KeyHashSHA256 hash veya plain:key (sadece dev)
Permissionsread, write, emergency yetkileri

3.2 gateway-targets.json - Sunucu Tanımları

{
  "GatewayTargets": {
    "Legacy": {
      "Nodes": [
        { "Id": "legacy-1", "BaseUrl": "http://localhost:39414", "Enabled": true, "Weight": 100 }
      ]
    },
    "New": {
      "Nodes": [
        { "Id": "new-1", "BaseUrl": "https://localhost:52201", "Enabled": true, "Weight": 100 }
      ]
    }
  }
}
AlanAçıklama
IdBenzersiz sunucu kimliği
BaseUrlSunucu adresi
EnabledSunucu aktif mi (global toggle)
WeightYük dengeleme ağırlığı (1-1000)
💡 Load Balancing:
Weight: 100 + Weight: 300 = İlk sunucu %25, ikinci %75 trafik alır

3.3 ocelot.json - Route Tanımları

{
  "Routes": [
    {
      "Key": "auth-login",
      "UpstreamPathTemplate": "/moim/api/v1/internet/auth/login",
      "DownstreamPathTemplate": "/api/auth/login",
      "Priority": 10,
      "Metadata": {
        "Module": "Auth",
        "NewSystemPercentage": 50,
        "DisabledNodes": { "Legacy": [], "New": ["new-2"] }
      }
    }
  ]
}
AlanAçıklama
KeyBenzersiz route anahtarı
UpstreamPathTemplateGelen istek path'i
DownstreamPathTemplateHedef backend path'i
Metadata.ModuleModül kodu (opsiyonel)
Metadata.NewSystemPercentageBu endpoint için yeni sistem yüzdesi
Metadata.DisabledNodesBu endpoint için pasif sunucular

4. Yeni Sistem Entegrasyonu

Adım 1: Sunucu Tanımlama

gateway-targets.json dosyasına yeni sunucu ekleyin:

{
  "GatewayTargets": {
    "NewSystem": {
      "Nodes": [
        { "Id": "newsystem-1", "BaseUrl": "https://newsystem:443", "Enabled": true, "Weight": 100 }
      ]
    }
  }
}

Adım 2: Modül Tanımlama

appsettings.json'a modül bilgisi ekleyin:

"ModuleDefinitions": {
  "NewModule": { "Name": "Yeni Modül", "Description": "Açıklama" }
}

Adım 3: Route Ekleme

ocelot.json'a route ekleyin:

{
  "Key": "newmodule-endpoint",
  "UpstreamPathTemplate": "/newsystem/api/{everything}",
  "DownstreamPathTemplate": "/api/{everything}",
  "Metadata": { "Module": "NewModule", "NewSystemPercentage": 0 }
}

Adım 4: Feature Flag Ekleme

"FeatureManagement": {
  "NewModule_UseNew": {
    "EnabledFor": [{ "Name": "Percentage", "Parameters": { "Value": 0 }}]
  }
}
⚠️ Dikkat: Yeni bir target sistem tipi (Legacy/New dışında) eklerseniz kod değişikliği gerekir.

7. Güvenlik

API Key Oluşturma

# PowerShell ile SHA256 hash
$key = "my-secret-key"
$bytes = [System.Text.Encoding]::UTF8.GetBytes($key)
$hash = [System.Security.Cryptography.SHA256]::Create().ComputeHash($bytes)
$hashString = [BitConverter]::ToString($hash).Replace("-", "").ToLower()
Write-Host "sha256:$hashString"
🔒 Production'da:
  • plain:key formatı kabul edilmez
  • Sadece HTTPS URL'ler kabul edilir
  • IP literal ve localhost bloklanır
