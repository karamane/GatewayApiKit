1. Kurulum ve Başlatma

Gereksinimler

  • Node.js 18+
  • npm veya pnpm

Kurulum

cd gateway-admin-ui
npm install

Geliştirme Sunucusu

npm run dev

Uygulama http://localhost:3000 adresinde başlar.

Environment Variables

DeğişkenVarsayılanAçıklama
VITE_API_BASE_URLhttp://localhost:53000Gateway API adresi
VITE_DEV_SERVER_PORT3000Dev server portu
💡 İpucu: .env.local dosyası oluşturarak varsayılanları değiştirebilirsiniz.

5. API Entegrasyonu

API Servisleri

services/gatewayService.ts dosyası tüm API çağrılarını içerir:

FonksiyonEndpointAçıklama
getNodes()GET /nodesNode listesi
getNodeStatus()GET /nodes/statusSağlık durumları
setNodeEnabled()PUT /nodes/{id}/enabledNode toggle
getModules()GET /modulesModül listesi
setModulePercentage()PUT /modules/{code}/percentageYüzde ayarla
getSystemHealth()GET /system-healthSistem sağlığı

React Query Hooks

hooks/useApi.ts dosyası veri çekme ve mutasyon hook'larını sağlar:

import { useModules, useSetModulePercentage } from '@hooks/useApi';

// Veri çekme
const { data, isLoading, refetch } = useModules();

// Mutasyon
const setPercentage = useSetModulePercentage();
setPercentage.mutate({ moduleCode: 'Auth', percentage: 50 });

Yeni API Endpoint Ekleme

  1. Tip tanımla (types/*.ts): 
    export interface NewResponse { data: string; }
  2. Servis fonksiyonu ekle (gatewayService.ts): 
    export async function getNewData(): Promise<NewResponse> {
  return (await api.get('/new-endpoint')).data;
}
  3. Hook ekle (useApi.ts): 
    export function useNewData() {
  return useQuery({ queryKey: ['newData'], queryFn: getNewData });
}

7. Deployment

Production Build

npm run build

Çıktı: dist/ klasörü

Gateway'e Entegrasyon

# Windows
xcopy /E /Y dist\* ..\src\Gateway\ApiGatewayKit.Gateway\wwwroot\admin\

# Linux/Mac
cp -r dist/* ../src/Gateway/ApiGatewayKit.Gateway/wwwroot/admin/

Standalone Deployment

Herhangi bir statik dosya sunucusuyla (nginx, Apache, Caddy) sunulabilir:

# nginx örneği
server {
    listen 80;
    root /var/www/admin-ui;
    
    location /api {
        proxy_pass http://gateway:53000;
    }
    
    location / {
        try_files $uri /index.html;
    }
}
⚠️ Dikkat: Production'da VITE_API_BASE_URL'i doğru ayarlayın veya proxy kullanın.
